# mandalai.app

The Mandalai website: home, support and privacy policy. Plain static files served by GitHub Pages at https://mandalai.app (custom domain in `CNAME`).

Edit the HTML, push to `main`, and Pages republishes within a minute. Fonts: Instrument Sans as WOFF2 (SIL Open Font License, `fonts/OFL.txt`).

Home page: the App Store badges in `img/badge-*.svg` are Apple's official artwork (toolbox.marketingtools.apple.com) and must not be altered. Store images are `img/shot-N-520.jpg` / `-780.jpg`. `og-image.png` (1200×630) is the link preview; the Smart App Banner uses app id 6826711847.
